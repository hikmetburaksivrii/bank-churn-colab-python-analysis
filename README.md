🏠 **Project Overview:** The Bank Customer Churn dataset consists of customer information focused on understanding customers' tendency to stop using a bank's products and services. The dataset includes features such as credit score, country, gender, age, tenure at the bank, account balance, number of products, credit card ownership, active membership status, estimated salary and churn status, which indicates whether the customer has left the bank.

The main goal of this analysis is to identify the factors that cause churn and determine how strongly each factor affects it. The study examines demographic, geographic, financial, product-related and interaction-based factors. It distinguishes variables that carry a real churn signal from those that do not and investigates confounding variables and interactions between variables to identify high-risk customer segments. The ultimate goal is to support strategies aimed at reducing customer churn and strengthening customer loyalty.

🔄 **Project Workflow:** The Exploratory Data Analysis (EDA) process was carried out from start to finish using Python in Google Colab. The notebook consists of sequential sections, and this order must be followed because columns derived in earlier sections are used in later sections.

The workflow began with the data understanding stage, where the structure of the dataset was examined and data quality was checked. The overall churn rate was established as a reference value. The churn rate of each variable was examined by group, along with the number of customers (N). The strength of relationships was measured using Pearson and Spearman correlations, Mutual Information (MI), the Chi-Square test and Cramér's V. In the final stage, variable intersections were examined to investigate interactions between variables, and all results were combined into a general summary table.
